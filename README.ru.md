## Что это

182 статьи про автоматизацию Blender: как вызывать Python API, не гадая; как
встраивать сторонние инструменты в пайплайн; и что реально ломается по дороге.
Каждый пример кода проверен на настоящей установке Blender до публикации —
что именно это значит, в разделе [Проверка](#проверка).

Тот же корпус выходит четырьмя способами, потому что четыре kinds читателя
нуждаются в разном:

| Поверхность | Для кого | Где |
|---|---|---|
| Статический сайт | люди | [`blender-mcp-wiki.r00m.ru`](https://blender-mcp-wiki.r00m.ru) |
| `.md`-близнец каждой статьи | кто скриптует | тот же URL + `.md` |
| `llms.txt` / `llms-full.txt` | ассистенты и индексы | `/llms.txt` |
| `wiki_database.json` | вашим инструментам | `WIKI/db/`, пересобирается |

## Языки — честное число

Корпус **полон на русском и английском**. На испанском, немецком и китайском —
по семь статей.

Эта формулировка намеренная. Предыдущая версия проекта публиковала 790
«переводов», которые были исходным текстом с шапкой «язык», и заявляла пять
языков. Это было неправдой. Сейчас число вычисляется из публикуемого множества,
а не из объявленного, и непереведённые зеркала остаются в репозитории как
бэклог перевода: страницы у них нет, потому что отдать читателю исходный текст на
выбранном им языке хуже, чем не отдать ничего.

## Быстрый старт

```powershell
# Всё: починить, собрать базу, собрать сайт, прогнать все гейты
$env:PUBLIC_SITE_URL="https://blender-mcp-wiki.r00m.ru"
python WIKI/scripts/run_all.py
```

```powershell
cd web
npm ci
npm run all     # сборка, тесты, гейты, preflight
npm run dev     # локальный сайт
```

`npm run all` — это гейт, который крутит CI. Он падает на битой внутренней
ссылке, на странице, которая опубликована но помечена `noindex`, на каноническом
адресе, расходящемся с origin, на инлайновом обработчике, который собственный CSP
сайта всё равно не выполнит, и на статье, чья метка `full` не выдерживает.

## Проверка

Утверждения здесь измерены, а не заявлены. Стоит знать вот это:

- **Каждый путь `bpy.*` из корпуса проверяется настоящим Blender.**
  `WIKI/scripts/api_compat.py` разбирает блоки кода, собирает пути API и
  разрешает их интроспекцией, не выполняя ни строки кода корпуса. Он нашёл, что
  `Mesh.use_auto_smooth` больше нет, что `bpy.ops.export_mesh.stl` стал
  `bpy.ops.wm.stl_export`, и что `bpy.ops.object.fluid_add` в 5.x не существует
  вообще. Двенадцать статей учили `action.fcurves`, который удалён слотированными
  Action. На какую версию нацелен корпус — открытое решение, оно в
  [`SDD/adr/0006`](SDD/adr/0006-blender-api-target-version.md).
- **Правило публикации живёт в одном файле.** `web/src/lib/publish.mjs` решает,
  у чего есть страница. Шесть переписанных вручную копий этого правила однажды
  разошлись и выпустили 19 страниц, которые были одновременно в индексе и с
  `noindex`.
- **Каждая опубликованная страница отснята скриншотом.** Все 304, на 390 / 768 /
  1440 px, с проверкой одного `<h1>`, отсутствия горизонтального переполнения,
  `<nav>` с подписью, ошибок консоли и неудавшихся запросов.
- **Непереведённые зеркала не могут уехать.** Запасного варианта `noindex` нет:
  зеркало без настоящего перевода не получает страницу, и гейт падает, если
  такое появится.
- **Гейты контента, а не только структуры.** `WIKI/scripts/content_quality.py`
  ловит проверку `bool(bpy.ops…)`, которая не может упасть, заглушки, пустые
  блоки кода, статью с меткой `full` тоньше контракта и один и тот же абзац,
  скопированный между статьями.

## Как участвовать

Читайте [`CONTRIBUTING.md`](CONTRIBUTING.md). Коротко: Markdown в `WIKI/` —
источник правды, пайплайн пересобирает всё остальное, и
`python WIKI/scripts/run_all.py` обязан закончить строкой `PIPELINE GREEN`.

Контракты лежат в `WIKI/templates/`: `DEPTH.md` про глубину статьи (включая
правило, что выдуманное имя API хуже честного пробела) и `TRANSLATION_RU.md` про
переводы.

## Известные ограничения

Говорю прямо, потому что справочник, который преувеличивает себя, хуже короткого:

- **Версия Blender не решена.** Корпус писался против 4.x, установлена 5.2.1 LTS,
  29 файлов вызывают API, которого в этой версии нет.
- **По 7 статей на испанском, немецком и китайском.**
- **Нет иллюстраций.** 196 статей, ноль картинок.
- **Ссылки на источники** на `docs.blender.org`, GitHub и прочие перестали нести
  `rel="nofollow"` — цитирование документации должно передавать ей авторитет.
