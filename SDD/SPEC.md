# SPEC — Blender AI Wiki

Версия спецификации: 3.0 · обновлено 2026-10-01.
Смежные документы: `ARCHITECTURE.md` (как устроено), `SEO.md` (продвижение),
`SCHEMA.md` (формат данных), `API.md` (контракт локального HTTP API),
`adr/` (почему так), `README.md` (статусы и запуск), `../web/README.md` (сайт).

## 1. Цель
Единая база знаний по Blender + MCP + AI-агентам: промпты, сетапы, воркфлоу, кейсы, референсы.
5 языков, полнотекстовый поиск, статический сайт, HTTP API, экспорт в CSV/Notion/Obsidian,
плюс машиночитаемый слой для AI-агентов (эта база).

## 2. Scope (фактическое состояние)
- **Промпты:** P01–P50, все уровня full. 50 файлов.
- **Сетапы:** 60 (41 full / 19 stub).
- **Воркфлоу:** 28. **Кейсы:** 16. **Референсы:** 19 + 10 однофайловых тем.
- **Языки:** en/ru/es/de/zh, паритет 163 файла на язык.
  Качество перевода маркируется честно: `human` (21 = 7 статей × 3 языка),
  `template` (427, шапка+оригинал), `legacy` (4).
- **БД:** 997 записей (182 оригинала + 815 переводов), ~516 тыс. слов, 5120 блоков кода,
  239 тегов, граф 997 узлов / 1426 связей.
- **Сайт (Astro 7, статика):** 916 пререндеренных страниц, из них 203 индексируемые,
  631 `noindex`-зеркало с каноническим адресом на оригинал, 163 shadow-зеркала не
  публикуются. Публикуется на Cloudflare Workers (static assets), не на Pages.
- **Машиночитаемый слой:** `llms.txt` v2, `llms-full.txt` (978 КБ), 834 markdown-близнеца,
  RSS, sitemap с hreflang-группами.
- **API:** 12 эндпоинтов, контракт 1.1, кэш БД по mtime, ETag/304, `POST` для мутаций.

## 3. Не-цели (границы)
- Публичный хостинг Python-API: только `127.0.0.1`, без авторизации и TLS.
  Он остаётся dev-инструментом; публикуется только статический Astro-сайт.
- Полный человеческий перевод всего корпуса (сейчас 7 статей из 182).
- SSR / on-demand рендеринг: контент неизменяем между сборками, статика быстрее.
- Полнотекстовый поиск по телу статей на сайте (Pagefind индексирует тело
  отрендеренных статей; полнотекстовая выдача с произвольными фильтрами —
  только в локальном API).
- Инкрементальная сборка БД.
- Подсветка синтаксиса кода (Shiki).

## 4. Критерии приёмки (проверяемые)
| # | Критерий | Как проверяется |
|---|----------|-----------------|
| 1 | Контент валиден | `python scripts/validate.py` → `RESULT: OK` (13 секций full-scan) |
| 2 | Регрессий нет | `python scripts/test_wiki.py` → 22 теста OK |
| 3 | Всё воспроизводимо одной командой | `python scripts/run_all.py` → `PIPELINE GREEN` |
| 4 | Данные не протухли | `content_hash` каждой записи == md на диске (тест) |
| 5 | SEO-слой корректен | `web/scripts/verify-seo.mjs` → `RESULT: OK` (203 статьи) |
| 6 | Артефакты согласованы | `web/scripts/verify-consistency.mjs` → `RESULT: OK` |
| 7 | Деплой безопасен | `web/preflight.mjs` → `PREFLIGHT: OK` (домен + лимиты Workers) |
| 8 | Поиск по базе работает | `/api/search?q=displacement` возвращает P41 первым |
| 9 | Спека не врёт | числа в §2 совпадают с БД; проверяет `validate.py` §12 |
| 10 | История есть | запись в `CHANGELOG.md` + отметка в `README.md` + коммит в git |

## 5. Маркировка статуса
- `status: full|stub` — только `setups/`, `workflows/`, `cases/` (там есть смысл «дописать»).
- `translation: human|template|legacy` — качество перевода; полный список human-зеркал
  в `scripts/wiki_const.py` (единственный источник для `mark_stubs.py` и `validate.py`).
- Промпты, референсы и переводы `status` не имеют by design.

## 6. Открытые вопросы (ждут решения владельца)
1. **Домен.** `PUBLIC_SITE_URL` — плейсхолдер `blender-ai-wiki.pages.dev`. Настоящий
   адрес появится после первого `wrangler deploy` (`*.workers.dev`) или после привязки
   своего домена. Меняется в одном месте (`web/astro.config.mjs`), пересборка обязательна.
2. **CI.** Гейты автоматизируемы (`run_all.py`, `npm run all`), репозиторий под git,
   но автоматического запуска пока нет. Шаг занимает ~3 мин — потребуется кэш `node_modules`.
3. **Ставка на переводы.** 7 из 182 статей переведены человеком; остальные помечены
   `template`, не индексируются и объявлены канонической версией — это честно, но
   это не «5 языков». Либо принять, либо инвестировать в перевод.
4. **Глубина содержания.** 80 файлов с пробелами в структуре, 63 `status: stub`.
   Счётчик — `WIKI/quality_report.md`.

## 7. Известный техдолг (измерен, не «когда-нибудь»)
| Объём | Что | Как закрыть |
|-------|-----|-------------|
| **80 файлов** | не хватает шаблонных секций (`СВЯЗИ`/`ЦЕЛЬ`/`MCP`) | `WIKI/quality_report.md` — список по файлам; после 0 файлов включить `validate.py --strict` |
| **63 stub** | сетапы/воркфлоу/кейсы уровня шаблона | `upgrade_top10.py` / `upgrade_top15.py` как образец |
| **161 файл** | переводы уровня `template` (не индексируются) | человеческий перевод батчами по 2–3 языка |
| **1 зависимость** | `PyYAML` не объявлена | фолбэк-парсер frontmatter готов и покрыт тестом (ADR 0004) |
| **~50% промптов** | английские заголовки секций в русской базе (`GOAL` vs `ЦЕЛЬ`) | два диалекта объявлены допустимыми: гейт проверяет наличие секции, не язык заголовка |
| 1 страница | подсветка синтаксиса кода не подключена | Shiki; влияет на размер, не на SEO |
| Поиск | индекс по метаданным, не по телу статьи | внешний индекс, если понадобится (ARCHITECTURE §5) |
