# ADR 0004 — Инструментарий на stdlib, API только на localhost

- **Статус:** принято
- **Дата:** 2026-09-28

## Контекст
Проект — база знаний на ~1000 статей, которая должна запускаться на машине автора и в
agent-сессии. Внешние зависимости (FastAPI, Flask, uvloop, pytest…) означали бы отдельное
окружение, `pip install` и версии, которые ломаются через полгода.

## Решение
1. Весь пайплайн (`run_all.py` и все шаги) — только стандартная библиотека Python 3.11+.
   Единственное исключение — `build_database.py` использует `PyYAML` для frontmatter.
2. API — `http.server.ThreadingHTTPServer`, слушает `127.0.0.1` по умолчанию.
3. Тесты — `unittest` (не pytest), запуск: `python scripts/test_wiki.py`.
4. Секретов и внешних вызовов в пайплайне нет.

## Последствия
- **Плюсы:** `python scripts/run_all.py` работает на любой машине с Python; воспроизводимость
  окружения не зависит от pip; восстановление из чужого окружения = скопировать папку.
- **Минусы/риски:**
  - **`PyYAML` — единственная внешняя зависимость, и она не объявлена нигде.** Если её нет,
    `build_database.py` падает на импорте. *Планируется:* фолбэк на минимальный разбор
    frontmatter при `ImportError` (полевая структура простая: `key: value` и `key: [a, b]`).
  - `http.server` не для продакшена: нет TLS, нет компрессии, нет лимитов. Это осознанная
    граница (SPEC §3), а не упущение.
- Требования к среде: `SDD/README.md` §«Окружение».
