# Deep research — что можно улучшить в Blender MCP Wiki

Дата: 2026-11-12. Проект: `blender-mcp-ai-wiki` (astro + Cloudflare Pages), корпус 182 оригинала.

## Вывод в один абзац

Сайт технически сделал почти всё, что обычно пропускают маленькие вики (hreflang, JSON-LD, честные языки, скриншоты всех страниц, измеренные проверки против реального Blender). Не хватает **авторитетных сигналов E-E-A-T** (подписи авторов, about/license/legal, ссылки на источники с нами без `nofollow` — это уже сделано), **распространения** (репозиторий на GitHub создан, но 0 звёзд и ни одного внешнего упоминания), **одного понятного позиционирования** против прямого конкурента — `ahujasid/mcp-for-blender` (34 022 звезды) и `arjun988/blender-skills` (2 499 звёзд) — и **данных о спросе**, которые никто не измерил. Самый дорогой пробел корпуса — отсутствие версии Blender: 29 файлов упоминают API, которых нет в установленной 5.2.1 LTS, и это обесценивает весь изложенный в статьях код для аудитории, которая пришла по ссылке из поиска.

## Ключевые находки

1. Конкурентный ландшафт измерен через GitHub API (256 repos по запросу `blender mcp`, 1280 всего): доминирует `ahujasid/mcp-for-blender` — 34 022 звезды, 3 100 форков, 57 открытых issue, последний пуш 2026-11-04, лицензия MIT, homepage `mcp-for-blender.com`. Direct play: **вертикальный справочник "bpy + MCP"**, не ещё один плагин.
2. llms.txt v2 (2026-08-10) формализовал практику: `.md` у каждой страницы, `rel="alternate"` → markdown, `rel="describedby"` → llms.txt, `Link:`-заголовки. Наш сайт удовлетворяет всему. Но спецификация сама предупреждает: llms.txt полезен для inference, не для обучения.
3. Google напрямую требует: видимый Q&A + авторство ("Is it self-evident to your visitors who authored"), иначе массовый AI-контент получает низкий effort-сигнал. Наш корпус — AI-assisted с нулевой видимой атрибуцией авторов.
4. Спрос не измерен ни одним инструментом — блок "что мы не знаем" (см. 03-GAPS.md). Звёзды на GitHub — косвенный сигнал, не трафик.
5. Технические основы в порядке: Pagefind, DCL 27 ms, 11.6 KB CSS gzip 3 KB, 0 JS на странице статьи, 100% страниц с hreflang и self-canonical, 0 битых внутренних ссылок. Дальнейшая работа над CSS/банде никого не выручит.
