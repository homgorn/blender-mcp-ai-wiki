## Сайт и API

- Сайт: открыть `site/index.html` (Static JSON) или `http://127.0.0.1:8099/site/` (API режим)
- API: `python scripts/wiki_api.py --port 8099` → `/api/search`, `/api/entry`, `/api/list`, `/api/graph`, `/api/version`, `POST /api/export` (контракт: `SDD/API.md`)
- Полный цикл одной командой: `python scripts/run_all.py`
- Пересборка: `python scripts/build_database.py` → `python scripts/build_graph.py` → `python scripts/build_site.py`
- Валидация: `python scripts/validate.py`
